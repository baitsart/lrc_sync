Script que sirve para crear Lyrics del sitio de Prem, cómo funciona: Carga la lista de Títulos, y te abre la letra del que elijas, ahí solo tocar la letra, hasta que quede la última linea, y listo el subtitulado.

Colocar lrc_sync_win.py (en Windows), o lrc_sync.py (en Linux), junto a gifts_album_yt.json (o cárgalo con el botón Cargar gifts_album_yt.json).

Asegúrate de tener,, en Windows mpv.exe instalado o en C:\mpv\mpv.exe y abre el script con python lrc_sync_win.py.

En Linux abre el script con python3 lrc_sync.py.
